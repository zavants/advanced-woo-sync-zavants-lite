# Advanced Woo Sync Lite

Free version of Advanced Woo Sync: real-time stock sync between two WooCommerce stores, for the products of one category (up to 50 products).

Order synchronization, unlimited products, SKU/tag/catalog filters, mass sync and stock comparison are available in [Advanced Woo Sync Premium](https://zavants.com/plugin-advanced-woo-sync).

Install: copy this folder to `wp-content/plugins/advanced-woo-sync-lite/` and activate it in both stores. See `readme.txt`.
